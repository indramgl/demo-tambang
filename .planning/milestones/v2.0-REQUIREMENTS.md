## Requirement Details

### REQ-008: Multilingual Routing
CI4 routes handle `/id/`, `/en/`, `/zh/`, `/fr/`, `/es/`, `/ja/` URL segments. Locale filter validates against supported list. Invalid locales redirect to `/id/`. `localeUrl()` method generates correct locale-prefixed URLs for navbar and hreflang tags.

### REQ-009: Static Page Templates
8 skeleton pages render with consistent layout via CI4 view rendering. About page added at `/id/tentang`. Layout bug fixed (`renderSection`). All pages use `$this->extend('layouts/main')`, `$this->section('content')`, `$this->endSection()`.

### REQ-010: Design Integration
CSS custom properties from design.md applied. Revolut Design System 2.0 components implemented. DesignSync extended with typography and elevation tokens. pages.css uses `var(--*)` references. CSS class selectors match HTML class names.

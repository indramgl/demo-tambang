### Requirement Details

**REQ-008 — Multilingual Routing:** Locale filter (`app/Filters/Locale.php`) validates URL locale segments and redirects invalid ones to `/id/`. 6 languages via URL path routing (`/id/`, `/en/`, `/zh/`, `/fr/`, `/es/`, `/ja/`). `localeUrl()` method generates correct locale-prefixed URLs for navbar and hreflang tags.

**REQ-009 — Static Page Templates:** 8 skeleton pages (home, about/tentang, history, vision-mission, services, contact, portfolio, investor) render via CI4 native `view()` with consistent layout. All pages use `$this->extend('layouts/main')`, `$this->section('content')`, `$this->endSection()`. About page added at `/id/tentang`.

**REQ-010 — Design Integration:** `DesignSync` extended with typography (12 roles × 4 properties = 48 tokens) and elevation (3 tokens) extraction from design.md. `tokens.css` contains all design tokens. `pages.css` fully migrated to `var(--*)` references. CSS class selectors match HTML class names.

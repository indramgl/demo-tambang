# Plan 02: Static Page Templates & Controller Methods

## Objective

Deliver 7 skeleton pages accessible in all 6 locales via URL path (`/id/`, `/en/`, etc.), each rendered with a consistent layout template (header, navbar, content, footer). This is the core user-facing behavior of Phase 1.

## Context

- Wave 1 (02-01-PLAN.md) must be complete — locale filter and route group are working
- `app/Views/layouts/` directory does not exist yet — needs creation
- `app/Views/pages/` exists with subdirectories (home, about, contact, services) but only has language subdirs (ID, EN, etc.) that are empty — these are from v1.0 and will be replaced
- `app/Controllers/Home.php` currently only has `index()` returning `view('welcome_message')`
- `app/Config/Routes.php` currently only has the locale group with `$routes->get('/', 'Home::index')` from Wave 1
- design.md section 4 specifies the layout structure and page sections (see design.md sections 4.1–4.3)
- The 7 pages are: home, history (sejarah), vision-mission (visi-misi), services (layanan), contact (kontak), portfolio (portofolio), investor (investor)
- View rendering is pre-render during deploy (not runtime markdown conversion) — controller methods prepare the view, markdown conversion happens in a deploy step

# Plan 02: Language Switcher + Design Token Integration

## Objective

Complete the language switcher by ensuring `localeUrl()` works end-to-end in navbar, and extend the design token system so `tokens.css` contains full typography and elevation data from design.md. Then migrate `pages.css` from hardcoded typography values to `var(--*)` references.

## Context

Plan 01 added `localeUrl()` to `Home` controller and made navbar.php use `$localeUrls` array passed from controller. This plan verifies that works and adds the design token integration.

`DesignSync` currently extracts only colors (1.1), spaces (1.3), and radii (1.4). It needs extension for typography (1.2) and elevation (1.5). The `extractTableTokens()` method exists and is reusable — it needs the right section numbers and regex patterns.

`pages.css` has hardcoded typography values (e.g., `.hero-title { font-size: 3rem; font-weight: 500; }`) that should reference `var(--*)` tokens. The mapping from design.md roles to CSS classes is documented in 02-RESEARCH.md.

Key design.md tokens to extract:
- Section 1.2 (Typography): 12 roles × 4 properties = 48 CSS custom properties like `--font-display-mega-size`, `--font-display-mega-weight`, etc.
- Section 1.5 (Elevation): 3 tokens — `--shadow-none: none`, `--shadow-focus: 0 0 0 0.125rem ring`, `--shadow-raised: 0 24px 64px rgba(17, 24, 39, 0.12)`

<task id="02-02-01" type="tdd">
<name>Extend DesignSync for typography and elevation token extraction</name>
<files>
- app/Commands/DesignSync.php
</files>
<action>
Add three new `extractTableTokens()` calls in `DesignSync::extractRootBlock()`:

1. **Typography (section 1.2)**: 
   ```php
   $typographyProps = $this->extractTableTokens($content, '1.2', '/^--font-/');
   ```
   The typography table in design.md has 6 columns (Peran, Font, Ukuran, Weight, Line Height, Letter Spacing). Each row needs to generate 4 CSS custom properties: `--font-{role}-size`, `--font-{role}-weight`, `--font-{role}-line-height`, `--font-{role}-letter-spacing`. The `extractTableTokens()` method currently extracts cell[0] as name and cell[1] as value. For typography, the cell[0] contains the role name and cell[1] contains the font value — but we need all 4 properties per row. This requires special handling: parse the row cells and generate multiple property names per cell.

   **Implementation approach**: For section 1.2, write a dedicated `extractTypographyTokens()` method that parses the markdown table, reads each row's cells, and generates `--font-{role}-{property}` entries. The role comes from cell[0], and the four property values come from cells[1-4] (Ukuran, Weight, Line Height, Letter Spacing).

2. **Elevation (section 1.5)**:
   ```php
   $elevationProps = $this->extractTableTokens($content, '1.5', '/^--shadow-/');
   ```
   The elevation table has Level, Nilai, Penggunaan columns. Generate `--shadow-none: none`, `--shadow-focus: 0 0 0 0.125rem ring`, `--shadow-raised: 0 24px 64px rgba(17, 24, 39, 0.12)`.

   **Implementation approach**: For section 1.5, write a dedicated `extractElevationTokens()` method that reads the table and generates the three shadow tokens.

3. Merge the new properties into the `$properties` array in `extractRootBlock()` before building the `:root` block.
</action>

DesignSync.php contains calls to extract typography and elevation tokens. `extractTypographyTokens()` and `extractElevationTokens()` methods exist. `extractRootBlock()` merges all three property types.</verify>

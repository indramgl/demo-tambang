# Plan 03: Page Caching + Test Suite Update

## Objective

Implement CI4 page caching in `Home::page()` and update the entire test suite to reflect the new architecture. The test files currently assert against obsolete code (`getRenderedContent`, `'content'` in view data, `RenderPages` command) and must be rewritten to verify the new CI4 view rendering pipeline.

## Context

Plan 01 refactored `Home.php` to remove `getRenderedContent()`, add `PageNotFoundException`, and pass `localeUrls` instead of `content`. Plan 02 extended `DesignSync` and migrated `pages.css` to `var(--*)`. But the test files still reference the old architecture:

- `HomeControllerTest.php` asserts `getRenderedContent` exists, asserts `'content'` in view data
- `RenderPagesTest.php` tests the deleted `RenderPages` command
- `PageViewsTest.php` doesn't include `'about'` in the pages list
- `LayoutTest.php` doesn't verify `renderSection('content')`
- `DesignSyncTest.php` doesn't verify typography/elevation tokens

Also, CI4's `$this->cachePage()` method provides per-page application-level caching, which complements the OpenLitespeed reverse proxy cache for a two-layer caching strategy.

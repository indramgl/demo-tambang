# Plan 03: Design Integration — Tokens, Components & Layout Styling

## Objective

Apply Revolut Design System 2.0 design tokens and components from `design.md` to all skeleton pages so that visiting any page in any locale shows correctly styled content (colors, typography, spacing, buttons, cards, nav, forms) with responsive breakpoints.

## Context

- Wave 1 (02-01-PLAN.md) must be complete — locale routing works
- Wave 2 (02-02-PLAN.md) must be complete — 7 pages render with layout in all locales
- `design.md` at project root contains all design tokens (section 1), component specs (section 3), layout specs (section 2), and CSS file structure (section 8)
- `public/assets/` directory does not exist yet — needs creation
- `app/Views/layouts/main.php` from Wave 2 already links to `base_url('assets/css/main.css')` but the CSS files don't exist yet
- Decision from 02-CONTEXT.md: auto-generate `tokens.css` from design.md via CLI command (`php spark design:sync`), sync runs as Composer `post-install-cmd`
- `composer.json` exists at project root — needs `post-install-cmd` script
- No CSS files exist in `public/assets/css/` yet
- The layout template already includes `base_url('assets/css/main.css')` from Wave 2

<action>
Create `app/Commands/DesignSync.php` — a CI4 CLI command (`php spark design:sync`) that: (1) reads `design.md` from the project root, (2) extracts the CSS `:root` block from section 1 (Design Tokens) using regex or string parsing, (3) writes the extracted CSS to `public/assets/css/tokens.css`. Also manually create the initial `public/assets/css/tokens.css` file with the exact CSS custom properties from design.md section 1 (all `--bg`, `--surface`, `--fg`, `--accent`, `--success`, `--warn`, `--danger`, `--border`, `--radius-*`, `--space-*` tokens). Register the command in `app/Config/Autoload.php` or ensure it follows CI4 command naming conventions (`DesignSync` class in `App\Commands` namespace with `run($params)` method).
</action>
<verify>
- `app/Commands/DesignSync.php` exists and is executable via `php spark design:sync`
- Running `php spark design:sync` creates `public/assets/css/tokens.css` with all CSS custom properties from design.md section 1
- `public/assets/css/tokens.css` exists and contains `:root` block with all design tokens
- All colors use `var(--*)` references — no hardcoded hex values in tokens.css outside `:root`
</verify>

<task id="02-03-02">
<name>Create CSS files (main.css, components.css, pages.css, responsive.css)</name>
<files>
- public/assets/css/main.css
- public/assets/css/components.css
- public/assets/css/pages.css
- public/assets/css/responsive.css
</files>
<action>
Create 4 CSS files in `public/assets/css/`: (1) `main.css` — imports tokens.css via `@import 'tokens.css'`, includes CSS reset (margin/padding 0, box-sizing border-box), base typography (Inter font family), container class with max-width 1180px and responsive gutters, and section spacing. (2) `components.css` — button styles (pill shape, 9999px radius, 14px 32px padding, primary-dark/secondary-light/outlined/ghost-on-dark variants), card styles (20px radius, var(--surface) background, 1px var(--border) border, flat no shadow), nav styles (Inter 20px weight 500, hamburger toggle), form field styles (1px var(--border) border, 12px radius, 12px 16px padding, var(--accent) focus ring). (3) `pages.css` — page-specific styles for hero sections, timelines, service grids, portfolio grids, contact form layout, investor document tables. (4) `responsive.css` — media queries at 720px (tablet, 2-column grid), 400px (mobile small, compact layout), matching breakpoints from design.md section 2.2 and 6.2. All colors must use `var(--*)` custom properties — no hardcoded hex values.
</action>
<verify>
- All 4 CSS files exist in `public/assets/css/`
- main.css imports tokens.css and contains reset + container + base typography
- components.css contains button, card, nav, form styles using var(--*) tokens
- pages.css contains page-specific layout styles
- responsive.css contains media queries at 720px and 400px breakpoints
- No hardcoded hex colors in any CSS file — all via var(--*)
</verify>

</task>

# Plan 01: CI4 View Rendering Pipeline

## Objective

Fix the core rendering pipeline so all 7 pages render correctly via CI4 view rendering. This is the foundational plan — without it, no pages display content. It replaces the obsolete pre-render markdown pipeline with CI4's native `view()` system, fixes the layout section bug, adds the missing about page, and removes all dead code.

## Context

The deep discussion (2026-09-19) established that CI4 view rendering replaces the pre-render pipeline. Current `main.php` has a critical bug: `<?= $content ?>` should be `<?= $this->renderSection('content') ?>`. `Home::page()` calls the obsolete `getRenderedContent()` which reads from `public/content/`. The navbar generates broken locale URLs (`/en/id/current-path`). The about page is missing entirely. `RenderPages` command and `public/content/` directory are artifacts of the old pipeline.

Key existing patterns:
- All page views already use `$this->extend('layouts/main')`, `$this->section('content')`, `$this->endSection()`
- `Home::PAGE_MAP` has 7 entries; needs `'about' => ['Tentang Kami', 'about']`
- `Routes.php` uses `$routes->group('{locale}', ['filter' => 'locale'], ...)` pattern
- `Locale.php` filter is already working correctly
- `composer.json` has `"post-install-cmd": ["php spark design:sync"]` — no RenderPages reference

# Plan 01: Locale Filter & Route Group Setup

## Objective

Deliver multilingual URL routing so that every page is accessible via a locale-prefixed path (`/id/`, `/en/`, etc.) and invalid locales gracefully redirect to the default (`/id/`). This is the foundation all subsequent page rendering depends on.

## Context

- CI4 4.7.4 project at `C:\Coding\perusahaan-tambang`
- `app/Config/Routes.php` currently has only `$routes->get('/', 'Home::index')` — no locale routing
- `app/Config/App.php` has `$defaultLocale = 'en'` and `$supportedLocales = ['en']` — needs expansion to 6 locales
- `app/Config/Filters.php` has no custom filter aliases yet
- No `app/Filters/Locale.php` exists yet
- Decisions from 02-CONTEXT.md: custom filter class, route-level redirect for root, filter applied to locale route group
- `{locale}` is a CI4 reserved placeholder — only usable in `$routes->group('{locale}', ...)`, never in custom route definitions (per RESEARCH.md)

## Tasks

<task id="02-01-01">
<name>Create Locale filter class</name>
<files>
- app/Filters/Locale.php

<action>
Create `app/Filters/Locale.php` implementing `CodeIgniter\Filters\FilterInterface`. The `before()` method must: (1) extract the locale segment from the URI (first path segment), (2) validate it against `['id', 'en', 'zh', 'fr', 'es', 'ja']`, (3) if invalid, redirect to `/id/` with HTTP 302 using `redirect()->to('/id/')`, (4) if valid, call `$request->setLocale($locale)`. The `after()` method should be empty. Use the CI4 `FilterInterface` contract with `before(RequestInterface $request, $arguments = null)` and `after(RequestInterface $request, ResponseInterface $response, $arguments = null)` signatures.
</action>
<verify>
- File `app/Filters/Locale.php` exists and contains a class `Locale` implementing `FilterInterface`
- `before()` validates locale against the 6 supported codes and redirects invalid ones to `/id/`
- `before()` calls `$request->setLocale($locale)` for valid locales
- `after()` is present (can be empty)
</verify>

</task>
